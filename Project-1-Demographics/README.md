# Project 1 - Demographics Analysis

## Objective
To analyze demographic characteristics of clinical study subjects using SAS.

## SAS Procedures Used
- PROC SORT
- PROC FREQ

## Analysis Performed
- Subject demographic data analysis
- Treatment group distribution
- Frequency and percentage calculations
- Categorical variable summaries

## Skills Demonstrated
- SAS DATA Step
- PROC SORT
- PROC FREQ
- BY-group processing
- Frequency and percentage reporting

## Output
The analysis generates frequency tables showing the distribution of subjects across demographic and treatment-related categories.
