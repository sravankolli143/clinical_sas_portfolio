# Clinical Demographics Analysis

## Project Overview
A beginner-level Clinical SAS programming project
using a fictional clinical trial dataset.

## Objectives
- Create a SAS dataset using the DATA step.
- Display observations using PROC PRINT.
- Summarize age using PROC MEANS.
- Generate frequency tables using PROC FREQ.

## Tools
- SAS
- GitHub

## Dataset
Contains 8 fictional participants with:
- Subject ID
- Age
- Sex
- Treatment group

## Disclaimer
This project uses synthetic data for educational
purposes only. It is not a validated clinical analysis.
