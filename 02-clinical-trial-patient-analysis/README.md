# Project 02: Clinical Trial Patient Analysis

## Overview
This project uses SAS to analyze a fictional clinical trial dataset containing 20 patients. The analysis explores patient demographics, treatment groups, age, weight, and study completion status.

## Dataset
- Dataset: clinical_trial
- Number of fictional patients: 20
- Variables: SUBJID, AGE, SEX, TRTGRP, SITE, WEIGHT, STATUS

## SAS Procedures Used
- PROC PRINT – Display patient records
- WHERE statement – Filter patients by treatment group, age, and status
- PROC SORT – Sort patients by age or weight
- PROC FREQ – Frequency tables and treatment-by-status cross-tabulation
- PROC MEANS – Summarize age and weight
- IF-THEN/ELSE – Create age groups
- BY-group processing – Summarize data by treatment group

## Key Learning Outcomes
- Filtering and sorting clinical trial data
- Creating derived variables such as AGEGRP
- Producing frequency tables and descriptive statistics
- Comparing treatment groups and patient status

## Tools
- SAS
- GitHub

## Disclaimer
All patient data in this project are fictional and created for learning purposes. This project is not based on real clinical trial participants.
