# Project 2 - Treatment Analysis

## Objective
To analyze clinical study treatment groups and summarize subject status using SAS.

## SAS Procedures Used
- PROC SORT
- PROC FREQ

## Analysis Performed
- Treatment group analysis
- Subject status analysis
- Frequency and percentage calculations
- Categorical data summarization

## Skills Demonstrated
- SAS DATA Step
- PROC SORT
- PROC FREQ
- BY-group processing
- Frequency and percentage reporting

## Output
The analysis generates frequency tables summarizing subjects by treatment group and study status.
